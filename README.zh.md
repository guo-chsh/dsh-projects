# dsh-projects

**简体中文** | [English](./README.md)

把多个物理目录组织成一个「项目」，并在左侧栏按 **项目 → 会话** 分组；会话在主工作区中启动，其余文件夹作为同一项目的附加目录。

```
项目
├─ A项目                ＋  ⚙
│  ├─ A项目会话1
│  └─ sub会话        (sub)      ← 该会话 cwd 落在附加文件夹
└─ B项目
   └─ B会话
其他会话                        ← 不属于任何项目的会话
```

## 安装

本包是一个 DSH profile bundle：npm 包 + `dsh.bundle.patch`（加载器补丁）+ `dsh.client`（浏览器半边）。

```text
plugin_manager install_bundle  target: "@guo-chsh/dsh-projects@0.1.4"
```

或直接装本地目录：`install_bundle` 的 target 传本仓库目录的绝对路径。

安装后：

1. 左侧栏出现「项目」面板入口；
2. 点它打开项目管理页 → 「新建项目」→ 选主工作区目录 → 可追加其它文件夹；
3. 回侧栏点项目行的 `＋` 在该项目内新建会话。

卸载/回退：

- 完全卸载：`plugin_manager remove_bundle`，target 用包名；
- 只恢复官方侧栏浏览区：把 `$DSH_HOME/projects.json` 的 `settings.sidebarTakeover` 改成 `false` 并刷新页面（项目管理页与会话工具仍然可用）。

## 风险与隐私

安装前请确认你能接受这三点：

1. **可选的全盘访问**：项目默认 `fullAccess: true`，会在项目内会话创建时把它切到部署的 `danger-full-access` 权限预设。代价是**该会话整体失去文件沙箱**（不只项目目录），因此项目外路径也不再被拦。不需要就取消勾选，会话会保留你自己的权限档。
2. **写本地文件**：`$DSH_HOME/projects.json`（项目注册表 + 手动归类）与 `$DSH_HOME/project-memory/<项目 id>.md` / `.messages.json`（共享记忆与会话消息）。删除项目会连带清理它自己的记忆与消息文件。
3. **内容进入模型提示**：共享记忆与会话消息会被注入到该项目会话的系统提示上下文（记忆最多 4000 字、每步最多 12 条未读消息），因此其中的内容视为会发给模型提供商。

## 结构

| 位置 | 作用 |
|---|---|
| 侧栏面板图标「项目」 | 打开主面板的项目管理页（新建 / 编辑 / 删除项目） |
| 项目管理页 | **两层视图**：先是一张项目列表（每行：名称 + 非默认状态标签 + 主工作区路径 + 文件夹数 + 打开/编辑/删除），点「编辑」或行主体进入该项目**详情**，详情顶部有「← 全部项目」返回。详情内依次是标题栏（名称 + 标签 + 打开/编辑/删除）→ 「工作区」表格（类型 / 文件夹 / 路径，主工作区高亮）→ 「共享记忆」**常驻展开**的编辑区（15px 加粗标题 + 说明行、等宽字体、高 360px 且可拖高至 65vh、底部大小计数、保存/清空）→ 「会话消息」同样**常驻展开**，标题右侧开关直接启用/停用，下方是消息流与输入框。记忆只会在打开详情时读取一次，之后 Host 重渲染不会覆盖正在编辑的草稿。编辑表单沿用同一套分节、开关与表格语言，文件夹增删在表格内完成。按钮与输入框由页面级 class 提供 hover / focus / active 反馈，主按钮使用 DeepSeek 蓝（`--dsw-static-deepseek-500`）而非主题里接近黑色的 `brand-primary`。 |
| 侧栏会话区（接管） | 「项目 → 分区 → 会话」三段式树；项目行有 `＋`（在主工作区新建会话）与 `⚙`（回管理页）；归档会话默认隐藏，标题栏可切换 |
| 项目内的分区 | 每个项目下按文件夹分节：`主区 · <目录名>`（主工作区）→ 其余附加文件夹（📁 + 目录名）。每节可单独折叠，节头显示会话数与进行中数量；会话归属哪个文件夹只由所在分区表达，行内不再有 chip |
| 全局置顶 | 侧栏最上方一个 **`★ 置顶`** 区块（不可折叠，始终展开），列出所有项目中已置顶的会话，排在「项目」之上；置顶行标题后带**目录徽标**——属于项目时显示 `主区 · A` 或附加文件夹名，不属于任何项目时显示它自己工作目录的目录名（悬停给出完整路径），字重略高，因为它不像其它会话那样躺在所属文件夹分节里。置顶/取消置顶仍走会话右键菜单或官方的 pin 菜单项 |
| 完成提示 | 会话从「进行中」变为「回复完成」时，**无论窗口是否在前台**都会发一条**系统桌面通知**（标题「回复完成」、正文是会话名）：点它回到应用并打开该会话，否则 1 分钟后自动关闭。通知由页面（渲染进程）的 web Notification 发出——桌面 Host 是 Node 模式进程，拿不到 Electron Notification。只有系统通知完全发不出去（无 API / 权限被拒）时，才退回右下角的应用内对话框（同样 1 分钟、点击打开会话、从下往上堆叠最多 5 条）——两者不会同时出现。子代理会话与空白草稿不提示；项目页右上角「测试通知」可预览 |
| 会话行图标 | 沿用 DSH 原版会话行的**状态圆点**（16px 单元格 + 8px 圆点），**不含字母、不表达文件夹**；等待你回复时额外在圆点右下角挂琥珀色角标（脉动） |
| 其他会话 | 不属于任何项目的会话：先是一个 `★ 置顶` 节（这些会话同样可从右键菜单取消置顶），再按 DSH 工作区分节（节头 = 工作区标题或目录名，`title` 为完整路径，可折叠），最后是「未归入工作区」节 |
| 会话右键菜单 | 右键会话行（或点行尾 `⋯`）打开原版菜单：置顶 / 重命名 / 分叉 / 归档 / 复制会话 ID —— 这些是 `sidebar.workspaces.session.menu.item` 里的官方条目，本插件只提供承载面板；若该列表未交付，则退回自绘的同一组动作（置顶 / **重命名** / 归档 / 分叉 / 复制 ID / 打开，重命名走自带的轻量对话框）。菜单底部另有「**移动到文件夹…**」二级面板：按项目分组列出全部文件夹，最下面始终是「**默认工作区**」（取消手动归类、回到按会话真实 cwd 归组）；选择后都会弹出一条结果提示，因为菜单点完即关闭 |
| 手动归类 | 归类只改变侧栏树里的位置（持久化在 `projects.json` 的 `assignments`），**不会改变会话真正的工作目录**——DSH 的会话与工作区是 `cwd === workspace.path` 强绑定，没有跨目录迁移接口；被手动归类的会话行 `title` 会注明「已手动归入；会话实际运行于 <cwd>」，提示上下文也会说明这条事实 |
| 会话状态 | 与官方会话行一致的状态圆点（16px 单元格 + 8px 圆点），**进行中例外：用一个经典 loading 环**（灰轨道 + 品牌色旋转弧，`dsh-projects-spin` 1200ms）：**进行中** = loading 环 ＋行尾「进行中」；**待确认** = 琥珀圆点 ＋ 行尾「待确认」＋ 右下角琥珀角标；**回复完成未读** = 绿色圆点；**已读/空闲** = 中性 `state-idle` 圆点；空白草稿行不画圆点（同官方）；等待用户时额外在圆点右下角挂琥珀色角标（脉动） |
| 选中会话 | 整行品牌色浅底 + 左侧 2px 品牌色竖条 + 标题加粗（`color-mix` 混色，跟随深浅色主题）；未选中行仅 hover 时用 `bg-layer-2` |
| 项目行 | 项目色小方块 + 名称 + 进行中数量徽标（带呼吸小点） |
| 项目颜色 | 可选，10 色固定调色板（蓝 / 靛 / 紫 / 品红 / 粉 / 青 / 蓝绿 / 翠绿 / 黄 / 橙，**不含红色**）。未设置时按项目 id 稳定推导，同一项目永远同色。颜色用于侧栏项目行与分区节头的小圆点、项目卡片的左侧强调条与标题前圆点；编辑表单里以色块选择，另有「自动」表示回到推导色 |
| 配色约定 | 项目色相取自固定调色板，**跳过红（0–20、335–360）与琥珀（20–55）**：红色只表示错误，琥珀只表示「待确认」，因此项目色方块与角标永远不会读成告警 |
| 会话标题旁 chip | `项目名 · 主区 A` 或 `项目名 · 当前 sub`，`title` 里给出主工作区与当前文件夹的完整路径，点击回到管理页 |
| 模型上下文 | 会话 cwd 落在项目任一文件夹（含子目录）时，Host 注入项目名、主工作区、附加文件夹清单与文件访问方式；记忆内容逐行加 `\| ` 引用、留言按 JSON 编码并限长 2000 字，因此存储内容无法伪造提示结构 |
| 跨文件夹读写 | 项目默认 `fullAccess: true`：在项目内启动的会话由 Host 切到 `danger-full-access` 预设，于是 A(代码)/B(需求)/C(用例) 等文件夹互通、不弹审批；在项目表单里取消勾选即改为 `false`，该项目的会话保持你自己的沙箱策略（此时提示上下文会说明"其余文件夹可能只读"） |

会话归属按 **cwd 前缀** 判定（取最长匹配的项目文件夹），所以同一项目下的多个文件夹天然归到同一项目节点，不受官方「会话必须与工作区路径完全相等」的限制。

## 使用

1. 点侧栏「项目」→「新建项目」→ 选择主工作区目录（会话将在其中启动）→ 可继续「添加文件夹」加入同一项目的其他目录 → 保存。
2. 回到侧栏，点项目行的 `＋` 新建会话；或点已有会话行打开。
3. 会话再多文件夹时，标题旁 chip 会显示它当前落在哪个文件夹。

## 数据与配置

`$DSH_HOME/projects.json`（缺省 `~/.dsh/projects.json`）：

```json
{
  "version": 1,
  "settings": { "sidebarTakeover": true },
  "projects": [{ "id": "…", "name": "A项目", "primaryPath": "C:/work/A", "folders": ["C:/work/A-extra"], "fullAccess": true, "messaging": false, "color": "#3b82f6", "createdAt": "…", "updatedAt": "…" }]
}
```

- `fullAccess`（每个项目，默认 `true`）：开启时，在该项目中启动的会话由 Host 在 `agent/created` 里切到部署的 `danger-full-access` 预设，因此项目内所有文件夹可读写且不弹审批。**代价是该会话整体无沙箱**（不只项目目录）——DSH 只支持一个可写根，没有"部分授权"的粒度。设为 `false` 后会话保留你原本的权限档，提示上下文会明确告知"其余文件夹可能只读"。可在项目表单勾选切换。

- `messaging`（每个项目，**默认 `false`**）：会话间消息的开关。关闭时提示上下文不含消息段、`project_message` 工具直接报错、面板只显示"已关闭"与开启指引；开启后项目内会话可异步互发便签（广播或定向），总线保留最近 300 条、提示里最多投递 12 条未读/步。可在项目表单勾选切换，卡片上会显示对应徽标。

- `settings.sidebarTakeover`：`true`（默认）接管侧栏渲染「项目 → 会话」；改成 `false` 后本插件不再接管，恢复官方「工作区 → 会话」浏览区（项目管理页与会话 chip 仍在），刷新页面生效。改动在下次读取时按文件 mtime 自动生效。
- 写入前校验绝对路径且必须是已存在目录；项目 id 只允许 `[A-Za-z0-9_-]{1,64}`（会拼进文件名）。所有写盘都经过"按文件排队 + 唯一临时名 + rename"的原子替换，两个会话同时写记忆/总线不会互相截断；已读回执同样排队原子写，进程崩溃时消息只会重复而不会丢失。
- 注册表缓存按 `mtime + size` 失效；JSON 损坏时会把原文件改名为 `projects.json.corrupt-*` 并以空注册表继续（错误进 Host 日志），未知的 `settings` 键在重写时原样保留，版本号高于本插件时只告警不拒绝读取。

## 项目房间：共享记忆与会话消息

同一项目的会话共用两样东西，用于跨会话协作：

| 通道 | 存储 | 形式 |
|---|---|---|
| 共享记忆 | `$DSH_HOME/project-memory/<项目 id>.md` | 一段 Markdown 笔记。每个项目会话的**每一步**都会重新读到它（`systemPrompt.context` 每步求值），所以新建会话、上下文压缩之后都不会丢；模型用 `project_memory` 工具读取/追加/替换/清空，项目管理页卡片上的「项目记忆」可直接编辑。 |
| 会话消息 | `$DSH_HOME/project-memory/<项目 id>.messages.json` | 异步留言总线。会话用 `project_message` 工具广播（`to` 省略/`all`）或定向发给某个 session id；收件会话在**下一步**的上下文里看到未读留言，读到即标记已读（不重复出现），发件人不会收到自己的消息。项目管理页卡片的「会话消息」可查看并手动广播。 |

- 两个工具都由 Host 在部署提供 `tools` 服务时注册，只在会话 cwd 落在某个项目文件夹内时可用，项目外会话调用会报错；未安装 `tools` 服务的部署会跳过注册、不影响其他功能。
- 提示上下文里最多带 `4000` 字记忆（取最新部分）与 `12` 条未读消息，避免把上下文撑爆；磁盘上的记忆文件上限为 20 万字符（页面按字节显示计数、Host 上限按字符计）。
- 这是**异步**通信：不会打断对方正在进行的回合，等价于"留言板 + 共享笔记"，而不是会话间的实时对话。

## 已接管带来的差异

接管 `sidebar.workspaces` 后，官方的搜索、视图选项、拖拽排序、pin/fork/工作区重命名与删除对话框不再出现在该区域；本插件提供等价的常用操作：打开会话、新建会话、归档显示切换、项目内新建会话、跳转管理页。需要官方浏览器时按上面的 `sidebarTakeover: false` 回退。

## 开发与验证

三套离线测试，零外部依赖（只需 Node），从**本包根目录**运行：

```text
node _verify/projects-host-check.mjs      # Host 半：路由 / 校验 / CRUD / 提示上下文 / 工具 / 权限预设 / 手动归类
node _verify/projects-client-check.mjs    # Client 半：桩模块加载器 + 桩 React 驱动真实组件
node _verify/memory-e2e.mjs               # 共享记忆端到端：真实 HTTP + 真实磁盘 + 真实提示装配（32 项）
```

`_verify/` 只用于开发，**不会**进入 npm 发布包（`package.json` 的 `files` 白名单不含它，`npm pack` 仍是 10 个文件）。

- `projects-host-check.mjs`：假 ctx 驱动 Host 半（CRUD、校验、去重、提示上下文、项目记忆读写、会话消息投递与已读、工具注册、权限预设切换、手动归类校验）。
- `projects-client-check.mjs`：假模块加载器 + 桩 React 驱动 Client 半（分组、分区、置顶、隐藏规则、徽标、会话行图标/运行 loading/选中行、右键菜单与移动到文件夹、项目列表→详情、记忆可编辑回归、新建会话）。
- `memory-e2e.mjs`：临时 `DSH_HOME` + 真实 `http.createServer` + 真实文件，验证 403 fence、落盘字节、跨项目隔离、`append` 累积、4000 字截断、413 上限、重载存活、删除清理。

发布前建议本地跑一遍打包自检，确认 `files` 白名单没有漏文件（本地目录安装是 junction，不会应用 `files`）：

```text
npm pack --dry-run
```
